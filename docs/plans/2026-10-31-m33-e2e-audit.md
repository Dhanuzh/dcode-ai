# M33 — End-to-end audit (v1.0.33)

Status: implemented (fixes); ideas proposed

## How

- `crates/cli/tests/tui_pty.rs` runs the real binary in a pseudo-terminal
  against a local mock of the Anthropic streaming API (`ANTHROPIC_AUTH_TOKEN`
  is a dummy that only reaches the mock).
- Two opt-in explorations (`cargo test -p dcode-ai-cli --test tui_pty
  explore -- --ignored`) run every slash command, and the mid-turn controls,
  writing each screen to `target/e2e-screens.txt` / `target/e2e-turns.txt`.
- The non-interactive CLI was driven against a small Python mock.

## Covered

All ~95 slash commands (no crash), `-p` / `--json` / `--stream ndjson`,
`sessions`, `status`, `logs`, `spawn`, `resume`, `session export|import`,
`policy test`, `mcp list`, `doctor`, `config`, `models`, `memory`,
`worktrees`, `completion`, `ci`; Esc interrupt, steering (Enter while
working), queue (Tab), `!` shell, `@` mentions, Shift+Tab modes, dashboard.

## Fixed

| Finding | Fix |
|---|---|
| `/permission-bypass` turned every prompt off in one step | bare command explains; needs `/permission-bypass on` |
| `-p … --json` printed human text; `-p` in a pipe printed headers, "YOU", session/cost lines | `--json` → one JSON result; piped `-p` prints only the answer |
| `@file` + Tab needed two Enters to send | Tab adds the space after a file; Enter on a complete mention sends |
| `/init` wrote a commented `.dcode.toml` (old model ids) and an empty `.dcode-ai/instructions.md` whose placeholder text went out with every request | `/init` only writes `AGENTS.md`; an untouched scaffold is no longer sent |
| `/verify`, `/security-review`, `/second-opinion` reviewers stayed "running" in the agents rail | completion event sent when the reviewer finishes |
| Esc: "Run cancelled" printed as an error above the partial reply | partial reply stays, then `Interrupted · tell dcode-ai what to do instead` |
| `/retry` re-sent dcode-ai's own messages (review findings, notifications) | re-sends what the user typed |
| `/stop` said "cancelling current turn…" when nothing ran | says nothing is running / lists background jobs |
| `/compact` on a few-message conversation made a paid summary call for nothing | declines below ~4k tokens of conversation |
| 13 CLI subcommands had no `--help` text | added |
| `policy test` reason "Default mode default for `execute_bash`" | "refused: a known-destructive command …", "Default mode asks before `edit_file`" |
| `doctor` asked for `ANTHROPIC_API_KEY` (sign-in is OAuth) | shows signed in / not signed in per provider |

## Noted, not changed

- `/models` on the Claude API backend lists nothing when the catalog can't
  be fetched (deliberate: no built-in list).
- `/attach` right after `/fork` shows the old session's socket.
- `/compact` also saves each summary as a memory note.
- Non-TTY `resume` still shows the old boxed banner.
