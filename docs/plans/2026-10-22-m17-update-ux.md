# M17 — In-session update and a quieter prompt (v1.0.13)

Status: implemented

- `/update` (`--check`): install the latest release from inside a session;
  the welcome screen's "update available" line points to it. Shares
  `self_update::update` with `dcode-ai update`; downloads retry three times.
- `install.sh`: when `/usr/local/bin` isn't writable, ask (default
  `~/.local/bin`, so `dcode-ai update` never needs sudo); warn when the folder
  isn't on PATH or an older copy comes first.
- Clipboard image paste runs off the UI thread; the footer shows
  "⧗ pasting image…" until it lands (WSL reads the clipboard via PowerShell,
  which took seconds with a frozen screen).
- The empty prompt is just `> ` and the cursor (no "Try …" placeholder).
- A remembered startup permission choice is applied silently (the footer
  shows the mode).
