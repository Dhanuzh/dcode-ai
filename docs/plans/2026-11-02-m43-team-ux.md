# M43 — Team UX: menus, chat window, compact office, Tailscale (v1.0.44)

Status: implemented

From the user's screenshots after the first real calls.

- **Menus, not typing**: `ChoiceAction::Menu` (`tui/menus.rs`), the same
  for host and guests, shown even while the agent works. The call menu (mute,
  push-to-talk, echo, volume → person → level, hang up), `/kick` → guest,
  `/todo done` → to-do.
- **Chat window**: the dashboard team tab as a chat app (bubbles, yours on
  the right; to-dos on top; an input box). `/chat` or `Alt+6` focuses it;
  it sends through a direct sink so chat works mid-turn.
- **Compact office**: `MiniOfficeView`, 12 columns × 7 rows per person, used
  in the dashboard when more than two are in the office.
- **Tailscale**: invite lines may list several addresses (`a,b:port/key`);
  `/invite` adds the Tailscale address; `join` tries each and explains a
  failure (different subnets → same Wi-Fi, hotspot or Tailscale).
  `dcode-ai setup tailscale` asks before running Tailscale's own installer.
  dcode-ai's installer never installs it.
- **Fix**: the host now forwards `PersonSeen` to guests, and a guest never
  times out on their own screen.
